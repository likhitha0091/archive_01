# BIRTHDAY SURPRISE — MASTER STORY

## PROJECT CONCEPT

This is a cinematic interactive birthday surprise website for a very close friend,
teacher, mentor, and "problem statement."

The experience should feel like an interactive memory film / digital memory archive,
NOT like a normal website and NOT like a literal page-turning book.

Use full-screen cinematic scenes, smooth transitions, animated avatars, image reveals,
typewriter text, subtle particles, depth, lighting, and emotional pacing.

The user navigates primarily using a subtle bottom-right ">" button.

DO NOT use a conventional navbar.
DO NOT use a button saying "Next".
The navigation symbol should simply be ">".

The website must be responsive and work beautifully on mobile and desktop.

# GLOBAL INTERACTION RULES

1. Use a bottom-right ">" navigation control.
2. Never write "Next".
3. Do not use a normal navbar.
4. Each scene should feel like a cinematic chapter.
5. Text should generally appear using typewriter / typing animation.
6. Important lines should appear one sentence at a time.
7. Use pauses between emotional/funny lines.
8. Images should use smooth reveal animations.
9. Use subtle zoom/parallax effects where appropriate.
10. Use cinematic transitions between scenes.
11. Do not make it look like a slideshow.
12. Do not use literal page-turning animations.
13. Keep the experience interactive and website-like.
14. Make it responsive for mobile and desktop.
15. Avoid excessive UI clutter.
16. Preserve the user's exact wording wherever provided.
17. Do not embed text directly into the photographs.
18. Text must be HTML/UI text layered beside or over the image.
19. Use the supplied image assets rather than inventing replacement photographs.
20. Do not create a backend.
21. Do not add Firebase.
22. Do not add a database.
23. Password authentication is frontend-only.
24. Prioritize visual polish, smooth animation and emotional storytelling.
